# Andrey Astapenko

**Machine Learning Engineer focused on industrial ML, NLP/RAG and computer vision.**

I build applied ML systems for real-world data: from leakage-aware validation and model evaluation to local applications, APIs and reproducible pipelines. My project experience includes microelectronics, steel microstructure analysis, retrieval-augmented generation and neural game systems.

## Featured projects

### [Multi-Agent RAG for Code Security](https://github.com/Maielafon123/Multi-Agent-RAG-CSec)

Local dual-retrieval system for code vulnerability analysis. It combines specialized agents, Qdrant, LangGraph, local LLM inference, structured decisions, FastAPI, Streamlit and multi-level evaluation of retrieval and final answers.

### [Steel Microstructure Analysis: CV + U-Net](https://github.com/Maielafon123/Steel-CV-U-Net)

Windows application for segmentation and morphometric analysis of SEM steel images. It supports classical computer vision and U-Net inference, batch processing, visual overlays and Excel export. The documentation explicitly separates agreement with weak pseudo-labels from independent expert validation.

### [MLChess](https://github.com/Maielafon123/mlchess)

A full-stack chess platform and experimental policy-value engine with supervised pretraining, PUCT MCTS, self-play data generation, Docker-based services, automated tests and a local monitoring dashboard.
